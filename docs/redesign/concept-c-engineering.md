# Концепция C — «Инженерная матрица» (Data-first B2B spec-sheet)

## Шапка

**Философия.** Главная — это **публичный data-sheet производителя**. Мы не продаём цену за тонну — мы продаём **воспроизводимость партии, химию и геометрию зерна, сертификаты и стендовые испытания**. В hero — живые цифры (SiO₂ %, морфология, ГОСТ-паспорта, дата последней партии), не слоганы. Каталог превращён в сравнительную таблицу со всеми техническими параметрами, фильтруемую по задаче. Главная цель — **вывести ЦМИД из ценовой гонки** и позиционировать как инженерного поставщика для стабильных крупных клиентов.

**Целевой пользователь.**
- **Первичная ЦА.** B2B-инженер-технолог крупного клиента: стекольный завод, водоканал и станции водоподготовки, производитель спортивных покрытий под госзаказ, крупный завод наливных полов. Для него соответствие ТУ и стабильность параметров важнее, чем цена за тонну.
- **Вторичная.** Закупщик крупного клиента (снабженец) — проверяет, что документы и сертификаты в порядке, и передаёт инженеру.
- **Исключена.** Розничный клиент, мелкий подрядчик, архитектор интерьера — они попадут на B или A.

**Главная метафора.** Техническая документация · приборная панель · лаборатория. Интерфейс отсылает к научным приложениям и data-dashboard'ам, а не к landing page.

**Базовая палитра под концепцию (черновик).** Белая бумага #FBFBF9 + чёрный #0D0D0D + один технический акцент — приборный жёлто-зелёный #B8D13A (цвет lab-индикаторов) или холодный циан. Моноширинный шрифт только для цифр, серьёзный sans для текста.

## Информационная архитектура (сверху вниз)

1. **Header** — технический: лого, **live-статусы** партии, навигация, «запросить образец»
2. **Hero — Live spec panel** — текущие показатели производства
3. **Fraction matrix** — сравнительная таблица 4 фракций × N параметров, фильтр по задаче
4. **Methodology** — как мы измеряем: стандарты, методы, частота
5. **Laboratory** — фото лаборатории, оборудование, протоколы
6. **Deposit / Mine** — геология, запасы, воспроизводимость
7. **Clients** — краткий список индустрий-клиентов (без лого, текстом)
8. **Document center** — скачать ГОСТ-паспорта, ТУ, сертификаты
9. **Contact engineer** — прямой контакт инженера продаж с фото
10. **Footer** — минимальный, с юрлицом и документами

## Раскрытие блоков

### 1. Header

- **Цель.** С первого взгляда показать «это производитель, а не перекуп».
- **Контент.** Лого ЦМИД · Фракции · Методика · Лаборатория · Месторождение · Документы · Контакт. Справа — компактный **live-индикатор**: «Текущая партия № X · от 18.04.2026 · SiO₂ 99.2% · паспорт →».
- **CTA.** «Запросить образец» (не «оставить заявку»).
- **Design hack.** Live-индикатор партии обновляется из внутренней системы (или имитирует обновление до интеграции). **Зачем:** это единственный элемент «живости» на сайте. Он молча говорит «у нас есть процесс, данные реальные, мы меняем партии». Доверие инженера — через мелкие сигналы, а не через громкие заявления.

### 2. Hero — Live spec panel ★ animation

- **Цель.** Заменить привычный маркетинговый hero на **панель данных**.
- **Контент.** Нет большого заголовка. Сетка 6–8 показателей:
  - `SiO₂ 99.2%`
  - `Fe₂O₃ < 0.03%`
  - `Влажность < 0.1%`
  - `Фракции: 4 марки · 0,1–5 мм`
  - `ГОСТ 22551-2019 · паспорт актуален`
  - `Партия № X · 18.04.2026`
  - `30 000 т/год`
  - `8 пунктов отгрузки`
- Каждое число — крупно, моноширинным. Под сеткой — одна серьёзная строка: «Кварцевый песок промышленного назначения. Соответствие ГОСТ и ТУ подтверждается паспортом каждой партии».
- **CTA.** «Запросить образец партии» + «Скачать ГОСТ-паспорт».
- **Design hack ★.** Один из показателей (например, дата партии) **пульсирует тонкой неон-линией** при загрузке; при наведении на любой показатель — всплывает методическая справка «как мы это измеряем». **Зачем:** инженер привык к дашбордам (SCADA, лабораторный софт) — эстетика узнаваемая и доверяемая. «Как измеряем» на hover — превентивно гасит главное возражение «откуда цифры».

### 3. Fraction matrix ★ animation

- **Цель.** Дать возможность сравнить 4 фракции по всем параметрам — **без перехода на карточку товара**.
- **Контент.** Большая таблица. Строки — параметры (SiO₂, Fe₂O₃, Al₂O₃, размер зерна, форма зерна, насыпная плотность, удельная поверхность, угол естеств. откоса, насыпная влажность, минимальная партия, упаковка). Столбцы — 4 фракции (0,1–0,3 / 0,5–1 / 0,8–2 / 2,5–5). Над таблицей — **фильтр задач** (тумблеры: стекло, фильтрация, наливной пол, пескоструй, бассейн, спорт, ССС); по клику — лишние столбцы уходят в приглушённый цвет, остаются подходящие.
- **CTA.** На каждой фракции-колонке — «Запросить образец» и «ТУ PDF».
- **Design hack ★.** Возможность **пиннить до 3 фракций** в режим «Сравнить» — отдельный sticky-блок внизу, где выбранные фракции показаны как 3-колонная карточка с графиком распределения зерна (chart.js/recharts). **Зачем:** это прямой аналог compare-инструмента Digi-Key/Mouser, привычного инженерам из электроники/химии. Там, где маркетинг пытается «скрыть сложность», инженер хочет её видеть.

### 4. Methodology

- **Цель.** Снять возражение «а как вы меряете, можно ли верить».
- **Контент.** 4–6 карточек-методик: ситовый анализ (частота, прибор), рентгенофлуоресцентный анализ (XRF), влажность (гравиметрия), морфология зерна (оптика). Каждая карточка — название метода, стандарт (ГОСТ/ISO), прибор, частота контроля.
- **CTA.** Ссылка «полное описание методик» → /methodology.
- **Design hack.** Карточки в стиле **technical sheet** — белый фон, моно-цифры, монохром. Никаких иллюстраций кроме микро-иконок прибора. **Зачем:** здесь визуальный декор противопоказан — сам визуальный язык должен быть «лабораторным».

### 5. Laboratory

- **Цель.** Визуально подтвердить: лаборатория есть, в ней люди, приборы, журналы.
- **Контент.** 3–4 крупных документальных фото: прибор XRF, ситовый стол, лабораторный журнал (даты видны), оптический микроскоп с экраном распределения зерна.
- **CTA.** «Виртуальный тур лаборатории» (если ресурс есть — video/3D).
- **Design hack.** Фото — не постановочные. Кабели, пыль, рабочие заметки на стене — **оставить**. **Зачем:** стерильные stock-фото «лаборатории» мгновенно считываются как фейк. Живая фактурная лаборатория — доказательство.

### 6. Deposit / Mine

- **Цель.** Показать, что мы владеем сырьём (снимает риск перерыва поставок).
- **Контент.** Краткая геологическая справка: месторождение, тип породы, запасы (тонн / лет), глубина, методика разработки. Схема разреза (можно простую иллюстрацию). 1–2 фото карьера.
- **CTA.** Нет.
- **Design hack.** Схема разреза — **SVG с подписями**, стиль геологической карты (контурные линии, штриховка слоёв). **Зачем:** это тот же приём, что у Русский Кварц — «технологический суверенитет». Владение запасами превращается в конкурентное преимущество перед перекупами.

### 7. Clients

- **Цель.** Показать отрасли, куда мы уже поставляем.
- **Контент.** Список отраслей текстом, без логотипов. Например: «стекольные заводы (2 поставщика в Центральной РФ), станции водоподготовки (4 региона), производители наливных полов (5 компаний), спортивные покрытия (2 подрядчика по программе госзаказа)». Без имён (NDA).
- **CTA.** Нет.
- **Design hack.** Плотная типографика без декора. **Зачем:** концепция C сознательно отказывается от витрины логотипов — она работает через фактическое описание, не через «звёзд». Инженер знает, что в его отрасли мало игроков, и ему достаточно «да, поставляем в водоканалы».

### 8. Document center

- **Цель.** Максимально упростить скачивание документов — это KPI страницы для инженера.
- **Контент.** Список: ГОСТ-паспорт по фракции × 4, ТУ × 4, сертификат соответствия × 4, санитарно-эпидемиологическое заключение, декларация соответствия, результаты независимой экспертизы. Фильтр по типу документа и по фракции.
- **CTA.** Скачать PDF (без формы! скачивание не требует email).
- **Design hack.** Таблица-список в стиле файлового проводника с иконкой типа файла, датой актуализации и весом. **Зачем:** **не прятать документы за формой** — это главный рычаг доверия. Инженер должен увидеть паспорт **до** разговора с продажами, а не после. Это повышает шансы, что к звонку он уже «на нашей стороне».

### 9. Contact engineer

- **Цель.** Дать прямой контакт ответственного инженера, не безликую форму.
- **Контент.** Фото инженера продаж, имя, должность, прямой телефон, email, мессенджер. Короткая подпись: «Отвечаю на технические вопросы по фракциям, подбираю под ваши ТУ, согласовываю партии». Форма «Запросить образец» рядом (простая: ФИО, компания, телефон, задача).
- **CTA.** Позвонить / написать / запросить образец.
- **Design hack.** Фото живое, не студийное; карточка визуально как LinkedIn-профиль, а не как «менеджер на сайте». **Зачем:** инженер хочет знать **с кем конкретно** он говорит. Безликая форма «мы свяжемся с вами» — антипаттерн для этой ЦА.

### 10. Footer

- Стандарт: юрлицо, ИНН, адрес, юридические документы. Без маркетинга.

## Логика переходов

**Основной сценарий (инженер).**
```
Header live-партия → Hero spec panel (увидел показатели)
                  → Fraction matrix (сравнил, выбрал 2)
                  → Methodology (проверил как меряют)
                  → Document center (скачал паспорт)
                  → Contact engineer (написал)
```
**5–7 минут чтения, 4–5 касаний, но это профессиональный sales-cycle.**

**Сценарий B (закупщик крупного клиента).**
```
Header → Document center → скачал документы
                        → Contact engineer (передал инженеру)
```
**Короткий путь для бюрократии.**

**Внешние переходы.**
- /methodology — из блока 4
- /laboratory — из блока 5
- /deposit — из блока 6
- /documents — из блока 8 (глубокий каталог документов)
- /catalog — **отсутствует как отдельная сущность**: каталог = Fraction matrix. Это философское решение: для данной ЦА карточка товара не нужна, её заменяет строка в таблице.

## Mobile-адаптация (375px)

- **Header.** Гамбургер. Live-индикатор партии сохраняется в виде короткой строки под шапкой (всегда видна). **Зачем:** на мобильном это главный «якорь доверия» — он не должен исчезнуть.
- **Hero spec panel.** Сетка 2×4 вместо 4×2. Цифры всё равно крупные. CTA — две кнопки стекаются вертикально.
- **Fraction matrix.** Таблица не помещается — превращается в **swipe-carousel карточек фракций**, где каждая карточка показывает все параметры этой фракции. Фильтр задач сверху остаётся. Режим «сравнить 3» на mobile — кнопка «Сравнить выбранные» откроет отдельный экран со сравнением.
- **Methodology.** Карточки стекаются вертикально, по одной на экран.
- **Laboratory.** Фото по одному в экран, вертикальный scroll.
- **Deposit.** SVG-схема масштабируется; текст справки под схемой, не рядом.
- **Clients.** Список остаётся плотным текстом — хорошо читается на mobile.
- **Document center.** Список растягивается на полную ширину, кнопка скачивания — большая, касанием.
- **Contact engineer.** Фото сверху, контактные кнопки (позвонить / написать / telegram) — крупные тач-таргеты. Форма «запросить образец» — полной ширины.
- **Footer.** Без изменений.

## Особое замечание для концепции C

Эта концепция **требует реальных данных**. Если нет актуальных паспортов партий, XRF-протоколов, лабораторных фото — страница будет выглядеть как обман (stock-photo лаборатории = мгновенный провал доверия у инженера). Перед переходом в Этап 3/4 нужно подтвердить:

- [ ] Есть ли актуальные ГОСТ-паспорта по 4 фракциям в PDF?
- [ ] Есть ли XRF-протоколы или другие химанализы?
- [ ] Можно ли сделать 3–4 реальных фото лаборатории (не стоковых)?
- [ ] Готовы ли раскрывать № партии и SiO₂ публично?

Если часть данных недоступна — концепцию можно адаптировать, но честно. Альтернатива: оставить концепцию в Figma на этап 3 как макет, но для кода (этап 4) выбрать A или B, пока данные не собраны.
